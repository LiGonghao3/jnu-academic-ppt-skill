# 暨大 PPT 模板

这里是五套暨南大学 PowerPoint 模板（.pptx），**不需要安装 AI 技能**，下载后用 PowerPoint 或 WPS 打开、替换文字即可使用。

| 文件 | 风格 | 适合场合 |
|---|---|---|
| 暨大PPT模板1-清爽简洁.pptx | 蓝色渐变、校园实景 | 社团、活动汇报 |
| 暨大PPT模板2-大气通用.pptx | 墨青、左侧章节导航 | 组会、论文精读 |
| 暨大PPT模板3-红色主题.pptx | 红绸、百年暨南 | 党团、思政活动 |
| 暨大PPT模板4-蓝色简约.pptx | 深青、顶部标签页 | 开题、中期、竞赛答辩 |
| 暨大PPT模板5-严谨有序.pptx | 蓝紫、中英双语 | 毕业论文答辩 |

**下载方法**：点开文件，再点右上角的下载按钮（Download raw file）。

**字体**：为控制体积，模板没有内嵌字体。模板 3、5 使用免费的思源宋体 / 思源黑体，建议先从 [Adobe Fonts 的 GitHub](https://github.com/adobe-fonts) 下载安装；没安装时 PowerPoint 会用系统字体代替。

**和原版的区别**：为减小体积，去掉了内嵌字体，过大的图片做了重采样，并清空了文件属性里的原作者信息；页面内容和版式与学校发布的原版一致。

想让 AI 根据你的周记、论文或素材自动排好整份 PPT，请看 [仓库首页的说明](../README.md)。
